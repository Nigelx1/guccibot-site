Found a bug? Open an issue on GitHub rather than messaging it. Not out of formality — a crash log in a thread can actually be symbolized and traced to the line that caused it, and it stays findable for whoever hits the same thing next. Attach the crash report Geode gives you, and say what you were doing when it happened. That has been enough to fix nearly every real bug this mod has had.
